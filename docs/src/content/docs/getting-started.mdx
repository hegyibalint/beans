## Get some Beans

<Tabs>
  <TabItem label="Binary">

Download the [latest release](https://github.com/hegyibalint/beans/releases/latest).
For now, releases are nightly development snapshots, not numbered versions.
Each published release is immutable; the latest links move forward as new
releases are published.

The initial binary is for **Linux x86-64**, built on Ubuntu 24.04. Compatibility
with older Linux distributions is not yet established. For other platforms,
use the **Sources** tab.

```sh
curl -fLO https://github.com/hegyibalint/beans/releases/latest/download/beans-lsp-linux-x86_64
curl -fL https://github.com/hegyibalint/beans/releases/latest/download/SHA256SUMS | sha256sum --check --ignore-missing -
chmod +x beans-lsp-linux-x86_64
```

Move `beans-lsp-linux-x86_64` to a directory on your `PATH`, renaming it to
`beans-lsp`, or configure your editor with its absolute path.

To pin a build, use its release-specific download link instead of `latest`.
Keep the release tag when reporting a bug. The release notes identify the exact
source commit and build workflow.

  </TabItem>
  <TabItem label="Sources">

<Steps>

1. Clone the repository:

   ```sh
   git clone https://github.com/hegyibalint/beans.git
   cd beans
   ```

2. Install [mise](https://mise.jdx.dev/getting-started.html).
   We use mise to manage Rust, JDKs, and Node.js (including npm). See
   [`mise.toml`](https://github.com/hegyibalint/beans/blob/main/mise.toml)
   for the tools we install.

   After installing it, fetch all required dependencies.

   ```sh
   mise install
   ```

3. Build the language server:

   ```sh
   cargo build --release --locked -p beans-lsp
   ```

   The language server is at `target/release/beans-lsp`
   (`beans-lsp.exe` on Windows).

</Steps>

  </TabItem>
</Tabs>

## Editor setup

### Visual Studio Code

The VS Code extension currently runs from the source checkout. After installing
the dependencies above, install VS Code's `code` command and run from the
repository root:

```sh
mise install
scripts/dev-vscode.sh
```

This builds Beans and opens the example Java project in a separate VS Code
window with the development extension loaded.

### Other editors

Beans communicates over standard input/output using the Language Server
Protocol. Point your editor's LSP client at the `beans-lsp` executable and
configure it for Java files. Editor-specific instructions will follow.
