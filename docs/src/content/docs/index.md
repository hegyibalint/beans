## One engine, across languages

Beans explores using the JVM as a common denominator for language tooling:
shared semantic information, exposed through libraries, developer tools, and a
language server.

## Native-first. Persistent. Reusable.

A Rust engine designed for fast startup, persisted semantic models, and tools
that can share the same understanding of your project.

Beans is in early development. Things are incomplete, and the shape of the
project is still evolving.
