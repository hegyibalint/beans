## Admonitions

:::note
Beans brings language tooling to the JVM ecosystem. See [Editor Setup](/beans/lsp/editor-setup/) for connection details.
:::

:::tip
Keep your editor’s language-server logs open while configuring Beans. They make connection issues easier to spot.
:::

:::caution
Beans is in early development. Expect missing features and rough edges.
:::

:::danger
Deleting a workspace removes its local files. Check the target directory and back up anything you need before continuing.
:::

## Shell and terminal blocks

Check the warm terminal surface, darker title bar, syntax colors, and copy button. Use the theme selector to compare dark and light mode throughout this page.

```sh title="Build Beans" frame="terminal"
# Build the language server from source
mise install
cargo build --release --locked -p beans-lsp
```

An untitled terminal uses the same treatment:

```sh
export RUST_LOG=info
./target/release/beans-lsp
```

Long commands should scroll inside the block rather than stretching the page:

```sh title="Long command" frame="terminal"
cargo test --workspace --locked --exclude beans-integration-tests -- --test-threads=1 --show-output
```

## Code and inline code

Compare an editor frame with the terminal frames above. The editor syntax colors currently come from Starlight’s code theme.

```rust title="hello.rs" {2}
fn main() {
    let project = "Beans";
    println!("Hello from {project}!");
}
```

Inline code such as `beans-lsp`, `RUST_LOG=info`, and `target/release/beans-lsp` should remain easy to read beside ordinary text and [documentation links](/beans/getting-started/).
