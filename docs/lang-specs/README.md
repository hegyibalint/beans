Run `python3 scripts/specs/update.py` (requires pandoc) to download the pinned JLS, JVMS, LSP, and JSON-RPC specifications as Markdown. Run `python3 scripts/specs/lsp.py` or `python3 scripts/specs/jsonrpc.py` to download only that specification.

Generated texts under `jls/`, `jvms/`, `lsp/`, and `jsonrpc/` are not committed.
