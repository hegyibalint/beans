## What is Beans

Beans is targeting to be an all encompassing, universal LSP for the whole JVM ecosystem.
Individual LSPs for major JVM languages exist, but they struggle to communicate with each other. Beans solves this. [Read more here](https://hegyibalint.github.io/beans/#how-is-it-different-from-other-jvm-language-servers).

## How to Beans

For now, Beans is in a pre-alpha stage, and not ready for general consumption.
However if you still want to check out what it can do for you, feel free:

```sh
mise install
scripts/dev-vscode.sh
```

This will open a development VSCode with some sample files, and Beans running. Enjoy!
